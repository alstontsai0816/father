這是什麼？

一個做父親節兌換券的小工具。你寫下想給爸爸的承諾，它會變成一條獨立的網址，爸爸打開就能一張一張撕下來兌換。

票券內容存在哪裡？

全部都在連結本身裡面。票券文字經過壓縮後編碼在網址的 # 之後——這一段依照 HTTP 規範不會被送到伺服器。標題、祝福語、名字永遠不會離開你的裝置和那條連結。

兌換記錄存在哪裡？

看有沒有接雲端（頁面上方的狀態列會說）：

  • ☁️ 已連線：兌換記錄存在 Supabase 資料庫，跨裝置同步，送禮的人也看得到「哪一張、什麼時候」被兌換。資料庫裡只有一組亂數 ID、票券編號、時間，沒有任何文字內容或個資。
  • 📌 純本機：兌換記錄只存在收禮者的瀏覽器裡。換手機、換瀏覽器、清快取就會歸零，送禮的人也看不到。

所以要注意什麼？

  • 連結就是權限。拿到連結的人都能看，也都能按兌換。內容只是家人間的祝福，不要放敏感資訊。
  • 改內容會產生新連結。舊連結仍然有效（兌換狀態也還在），記得重新傳一次新的。
  • 連結比較長。少數通訊軟體可能把它折行或截斷，建議用「複製連結」再貼上，別用手打。
  • LINE 內建瀏覽器不太可靠。沒接雲端的話，爸爸如果改用 Safari／Chrome 開同一條連結，會看到全新的未兌換狀態。這也是建議接雲端的主要原因。

可以離線用嗎？

可以。整個網站是單一個 HTML 檔，存到電腦或手機就能離線開啟（只有字體會退回系統預設）。離線時兌換會先記在本機，下次連上網路自動補送到雲端。
